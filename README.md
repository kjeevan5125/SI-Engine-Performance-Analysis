# Project 1 — SI Engine Performance Analysis

## Project Overview

Performance analysis of a 4-cylinder spark-ignition (SI) engine under different operating conditions using MATLAB and Microsoft Excel.

The project evaluates the variation of key engine performance parameters with engine speed and verifies the calculated results using independent engineering checks.

## Design Basis

- Engine type: 4-cylinder spark-ignition (SI) engine
- Operating condition: Different engine speeds
- Analysis approach: Analytical performance calculation
- Tools: MATLAB and Microsoft Excel

## Performance Parameters

The analysis evaluates the following engine performance parameters:

- Brake power
- Brake torque
- Brake specific fuel consumption (BSFC)
- Brake thermal efficiency
- Air-fuel ratio (AFR)
- Volumetric efficiency
- Fuel consumption

## Analysis

The Excel workbook contains structured engineering calculations for the engine operating conditions.

MATLAB is used to perform the numerical analysis, generate performance results, and plot the variation of engine parameters with speed.

The analysis includes:

- Engine displacement verification
- Brake power calculation
- Torque calculation
- Fuel flow and BSFC calculation
- Brake thermal efficiency
- Air-fuel ratio
- Volumetric efficiency
- Performance variation with engine speed

## Engineering Checks

The calculated results are cross-verified using independent engineering relationships.

The verification includes:

- Displacement verification
- Brake power consistency
- Fuel flow and BSFC consistency
- Brake thermal efficiency consistency
- Air-fuel ratio consistency
- Cross-verification between MATLAB and Excel results

These checks are used to ensure mathematical consistency and reduce calculation errors.

## Performance Plots

The project includes performance characteristic plots for:

1. Brake Power vs Engine Speed
2. Torque vs Engine Speed
3. BSFC vs Engine Speed
4. Brake Thermal Efficiency vs Engine Speed
5. Air-Fuel Ratio vs Engine Speed
6. Volumetric Efficiency vs Engine Speed

These plots are used to study the effect of engine speed on the overall performance characteristics of the SI engine.

## Conclusion

The project provides a structured analytical evaluation of a 4-cylinder SI engine across different operating speeds.

By combining MATLAB-based numerical analysis with Excel-based engineering calculations and verification, the project demonstrates the application of internal combustion engine performance concepts, engineering calculations, data analysis, and interpretation of engine performance trends.

## Scope

This project is an analytical/academic performance study. The calculated results are intended for engineering analysis and learning purposes rather than direct application to a production engine without experimental validation and detailed manufacturer-specific data.
