# SI-Engine-Performance-Analysis
Performance analysis of a 4-cylinder SI engine under different operating conditions using Excel and MATLAB.


# Excel Analysis
The Excel workbook contains the structured engineering calculations and performance results.
Located in: Excel folder
Excel is used to organize the input data, calculations, calculated performance parameters, and engineering checks.


# Results
The calculated results are stored in:
The results include the calculated performance parameters for the different engine operating speeds.
The analysis shows the expected variation of engine performance parameters with engine speed, including the relationship between torque, brake power, fuel consumption, BSFC, thermal efficiency, AFR, and volumetric efficiency.


# Performance Plots

The generated performance plots are available in: Plots Folder
The repository includes plots for:
  1.Brake Power vs Engine Speed
  2.Torque vs Engine Speed
  3.BSFC vs Engine Speed
  4.Brake Thermal Efficiency vs Engine Speed
  5.Air-Fuel Ratio vs Engine Speed
  6.Volumetric Efficiency vs Engine Speed
These plots are used to study the operating characteristics and performance trends of the modeled SI engine.


# Engineering Checks

Engineering consistency checks are included to verify that the calculated results are physically and mathematically consistent.
The checks include:
  1.Displacement verification
  2.Brake power calculation consistency
  3.Fuel flow and BSFC consistency
  4.Brake thermal efficiency consistency
  5.Air-fuel ratio consistency
  6.Cross-verification of calculated results
The purpose of these checks is to reduce calculation errors and ensure consistency between the MATLAB and Excel analysis.
